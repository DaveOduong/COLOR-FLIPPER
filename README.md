# COLOR FLIPPER

## 1. Project Description
Color Flipper is a simple web application built using HTML, CSS, and JavaScript. It allows users to change the webpage's background color by clicking different buttons.

## 2. Features
- **Green Button:** Changes the background to green.
- **Red Button:** Changes the background to red.
- **Blue Button:** Changes the background to blue.
- **Random Button:** Generates a random RGB color and applies it to the background.

## 3. Technologies Used
- **HTML:** Creates the webpage structure and buttons.
- **CSS:** Styles the buttons and defines their background colors.
- **JavaScript:** Handles button clicks and changes the webpage background color.

## 4. Project Files
- `index.html` – Contains the webpage structure and CSS styling.
- `script.js` – Contains the JavaScript functions responsible for changing background colors.

## 5. How to Run
1. Save the HTML code as `index.html`.
2. Save the JavaScript code as `script.js`.
3. Place both files in the same folder.
4. Open `index.html` in a web browser.
5. Click any color button to change the background.

## 6. JavaScript Functions

**setColor(name)**

Accepts a color name and changes the webpage background to that color.

**randomColor()**

Generates three random RGB values (Red, Green, and Blue), ranging from 0 to 255, and applies the resulting color to the webpage.

## 7. Conclusion
This project demonstrates basic JavaScript functions, DOM manipulation, event handling, and random number generation through a simple interactive webpage.
